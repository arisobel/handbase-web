# Internationalization and RTL

> **Status:** Active | **Last updated:** 2026-09-18

Initial locales:
- `en` — LTR
- `he` — RTL
- `pt-BR` — LTR

Requirements:
- UTF-8 end-to-end;
- document direction follows active locale;
- mixed Hebrew/Latin/numbers supported;
- logical CSS properties preferred;
- user labels may be entirely in Hebrew;
- internal identifiers remain neutral UUIDs/keys.
