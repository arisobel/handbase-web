# Product Overview

> **Status:** Active | **Last updated:** 2026-09-18

A small, fast, mobile-first personal/collaborative database inspired by HanDBase.

Users define tables, fields, records, relations and saved views.

The first use case is educational/community administration, but the core is domain-neutral.

Initial qualities:
- mobile-first;
- Hebrew RTL and English LTR;
- Portuguese as an additional locale;
- future RBAC;
- self-hosted deployment on CapRover.
