# Roadmap

> **Status:** Active | **Last updated:** 2026-09-18

## Phase 0 — Foundation
Repository seed, PostgreSQL, Docker/CapRover, React/FastAPI, EN/HE/PT-BR, metadata schema.

## Phase 1 — Core
Workspace, table builder, fields, record CRUD, basic view, search.

## Phase 2 — Saved views
Filters, sorting, visible fields, saved lists.

## Phase 3 — Relations
Linked records, 1:N/N:N, family/sibling-style navigation.

## Phase 4 — Auth and collaboration
Authentication, memberships, RBAC, record/field visibility, audit trail.

## Phase 5 — Follow-up
Timeline, tasks, due dates, reminders.

## Phase 6 — PWA/offline
Manifest, service worker, safe offline behavior, conflict strategy.

## Phase 7 — Import/export and automation
CSV/XLSX, export, API, automation hooks.
